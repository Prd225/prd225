### 🚀 Projeto em Destaque: SGM (Sistema Gerenciador de Mesas)

Atualmente lidero a concepção e evolução do **[SGM](https://github.com/prd225/sistema-gerenciador-de-mesas--sgm-)**, uma plataforma web *all-in-one* que centraliza mapas interativos, áudio, gestão de cenas, anotações e regras para mestres de RPG em um único ambiente.

* **Do Monolito à Arquitetura Modular:** Evoluiu de um protótipo estático (`HTML/JS`) para uma aplicação estruturada em **React + TypeScript + Vite**, com gerenciamento de estado desacoplado (`Zustand`) e canvas 2D interativo (`Konva`).
* **Validação Real & Iteração Lean:** Testado em **4 sessões reais com usuários**. Com base no atrito observado em uso, conduzo hoje a refatoração para um **Design System unificado**, redução de troca de telas durante o uso ativo e corte estratégico de escopo (remoção de camadas WebSocket em tempo real) para maximizar fluidez e foco no problema central.
* **Desenvolvimento AI-First:** Estruturado com engenharia de contexto, documentação arquitetural (`docs/ARCHITECTURE.md`) e CI/CD para garantir velocidade de entrega sem perder manutenibilidade.
